The question

What is the first product that will be fundamentally cheaper to make in microgravity, and at what launch, manufacturing and return costs is it viable?

The thesis being tested

Stem cells floating freely in microgravity avoid the stresses of flat 2D dishes, so a larger share of each batch turns into the correct, working cell type. Fewer wasted cells per batch means a lower cost per good cell.

How the calculator works

  1. Cost per batch. Add up everything one batch costs: cells, media, staff, facility; in space also launch, orbital lab fees and the return trip.
  2. Good cells per batch. Starting cells x growth x share that come out as the correct type x chance the batch passes testing (x survival of the trip home, for space).
  3. Cost per good cell = cost per batch / good cells per batch. Compare Earth with space.
  4. Check the assumptions. Each input is rated against the published evidence so you can see which numbers are solid and which are guesses.

Key limitations

  • The thesis lever (quality ratio r_q) has only been measured in small lab studies, several of them using simulated microgravity on Earth. No study has run a manufacturing-scale batch in orbit.
  • Earth already has 3D suspension culture (stirred bioreactors). The fair comparison is space vs the best Earth 3D process, not vs flat dishes.
  • The production comparison still includes orbital facility costs; it is not proof of an intrinsic microgravity effect.
  • Inputs are treated as independent unless a rule links them; g_S and q_S are derived from ratios.
  • Costs are expected expenditure per attempted batch (USD, 2026). No inflation or currency conversion.

Methods

Output per batch

g_S = g_E x r_g          q_S = q_E x r_q          (derived once; never sampled separately)
Y_E = N0 x g_E x q_E / U
Y_S_pre = N0 x g_S x q_S / U          Y_S = Y_S_pre x s
Q_E = p_E x Y_E      Q_S_pre = p_S x Y_S_pre      Q_S = p_S x Y_S

q is the fraction of cells in a successful batch that meet the qualification; p is the probability the whole batch is releasable; s is retention through return, storage and handling (viability and function together; never multiplied twice).

Costs per attempted batch

C_E_prod = sum of Earth production lines        C_E_del = C_E_prod + Earth delivery
C_S_prod = sum of space production lines        C_launch = L x M
C_S_del = C_S_prod + C_launch + return/recovery + other delivery
c_E_prod = C_E_prod / Q_E      c_S_prod = C_S_prod / Q_S_pre
c_E = C_E_del / Q_E            c_S = C_S_del / Q_S          Relative savings = 1 - c_S / c_E

Space is strictly cheaper when c_S < c_E. A tie is declared when |c_S - c_E| <= 1e-9 x max(c_S, c_E). Zero expected output with positive cost gives "No usable output" (infinite cost flag).

Break-even

L_max = (c_E x Q_S - C_S_prod - C_return - C_other_delivery) / M        (not applicable when M = 0)
r_g_min = C_S_del x U / (c_E x p_S x N0 x g_E x q_S x s)                 (holding everything else fixed)
Required output ratio: Q_S / Q_E must exceed C_S_del / C_E_del

Simulation

Pseudorandom generator: mulberry32 seeded with the user seed; stochastic inputs are sampled in a fixed order, so the same inputs and seed reproduce identical results. Triangular draws use the inverse CDF. Each draw represents one possible set of uncertain long-run parameters, and cost is expected expenditure divided by expected qualified output within that draw (single failed batches are not simulated). All stochastic inputs are independent; the only dependency rules are the derived g_S and q_S. Percentile bands are model percentile ranges, not confidence intervals. If a percentile falls in an infinite part of the distribution, it reads "No finite bound".

Validation

Costs, masses, counts and expansion factors must be >= 0; fractions and probabilities in [0, 1]; U > 0; triangular min <= mode <= max. max(q_E) x max(r_q) must be <= 1; q_S is never silently clipped.
